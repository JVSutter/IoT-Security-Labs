\section{Understanding of Dataset and Network Diagram}

This section examines the characteristics of the IoT-23 dataset, a collection of network traffic that groups benign IoT device operations with malicious botnet infections. To evaluate the dataset's composition, five specific malware scenarios were selected for analysis. The following table details the hardware environment, malware classifications and primary attack behaviors associated with each scenario. Additionally, a network topology diagram is presented to illustrate the controlled laboratory environment used during the research.

\section{Applying ML Algorithms to IoT-23 Data}

The accompanying Jupyter Notebook preprocesses the Mirai scenario and trains four classifiers to distinguish benign from malicious traffic. Data loading and numerical processing were implemented with pandas and NumPy \cite{pandas-2.3.3,harris2020array}.
The given data set was prepared to be used for training. To achieve training quality, missing/invalid values were replaced by NaN if numerical, or 'Unknown' if categorical. The label 'benign' was encoded as 0 and the label 'attack' as 1. The following class distribution is present before training:

\begin{center}
\begin{tabular}{|c|c|c|}
 \hline
 Class & Absolute count & Percentage  \\
 \hline
 0 - Benign & 1923 & 8.31 \\
 1 - Attack & 212222 & 91.69 \\
 \hline
\end{tabular}
\end{center}

During preprocessing, the numerical values were scaled using the scikit-learn StandardScaler while the categorical values were encoded using the OneHotEncoder \cite{scikit-learn}. Confusion matrices were plotted with Matplotlib \cite{Hunter2007}.
